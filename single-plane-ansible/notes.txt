This ansible configuration is for single control plane cluster
apply 
automation-setup.yml - Setups basic in all nodes
control.yml - Setups and initializes the control plane
woker.yml - Setups worker nodes and joins them to the control plane
cilium-config.yml - Configures the cilium CNF
hubble-cli.yml - Activaes hubble observability
prometheus-stack.yml - Setups Prometheus Stack
elk-stack.yml - Setups ELK stack with helm
